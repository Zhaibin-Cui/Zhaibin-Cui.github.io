RISC-V / FPGA / Real-time Systems

Real-time feed-forward for heralded quantum entanglement

I contributed to an FPGA/RISC-V quantum-control system that integrates photon timestamping, event detection, phase computation and DDS updates. The system calculates corrections from stochastic detection events and applies them to subsequent quantum operations with deterministic hardware timing.

The problem

Remote entanglement is heralded by stochastic photon detections, with arrival times affecting the entangled-state phase. Host scheduling and communication jitter make this path unsuitable for host-driven execution. Timestamp acquisition, phase compensation and cross-board synchronization therefore run on programmable hardware.

My contribution and implementation

  • Contributed to an FPGA-based RISC-V execution architecture. Microinstructions support conditional branches, loops, arithmetic and logic operations, and device routing, allowing experimental sequences to be modified in software.
  • Integrated the four-channel TDC, detection-window event logic, phase computation and DDS control for heralded-entanglement feed-forward, using the trigger/clock module to distribute compensation values.
  • Contributed to hardware-interface, firmware and host-software integration. Checked the control path from detector inputs through on-board computation to DDS outputs, and verified feed-forward operation using waveform measurements and coherent oscillations.

TTL / TDC

Acquire photon timestamps within detection windows, evaluate detection events and calculate phase corrections.

TCM synchronization and routing

Distribute a common clock, triggers and cross-board messages so control modules execute synchronized, deterministic sequences.

DDS / AWG output

Receive correction values and update amplitude, frequency or phase within the hardware-controlled sequence.

Experimental validation

The calibrated TDC achieves 11.5 ps RMS timing precision. The measured end-to-end feed-forward latency, including timestamp acquisition, phase calculation and waveform update, is approximately 800 ns. Restored coherent oscillations in a Ramsey experiment verify shot-by-shot phase compensation.

Related team work: QuCtrl-BELL

The QuCtrl-BELL work by She et al. describes a compiler architecture for this control platform. A Python DSL is lowered through CFG construction, SSA transformation, liveness analysis and register allocation into board-level programs, separating control flow from hardware state tables.

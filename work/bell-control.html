随机光子事件的实时量子前馈Turning stochastic photon events into deterministic control

参与 FPGA/RISC-V 可编程量子测控系统研发，连接光子到达时间测量、事件判断、相位计算与 DDS 更新。在真实硬件上，根据随机探测事件计算补偿，并以确定性时序执行后续量子操作。I contributed to an FPGA/RISC-V quantum-control system connecting photon timestamps, event decisions, phase computation and DDS updates. On real hardware, stochastic detection events become deterministic feed-forward for subsequent quantum operations.

要解决的问题The problem

远程纠缠通过随机单光子探测事件预报，光子到达时间会影响纠缠相位。主机操作系统的调度与通信抖动难以满足实时要求，因此需在可编程硬件上完成时间戳采集、相位补偿和跨板同步。Heralded remote entanglement depends on stochastic photon detections, and arrival time changes the entangled-state phase. Host scheduling and communication jitter are unsuitable for this path. Timestamp acquisition, phase compensation and cross-board synchronization must run in programmable hardware.

我的工作与实现My contribution and implementation

  • 参与 FPGA 内嵌 RISC-V 可编程执行架构研发，以微指令组织条件分支、循环、算术/逻辑操作与设备路由，使实验流程可通过程序调整。Contributed to the programmable execution architecture around RISC-V on FPGA. Microinstructions organize branches, loops, arithmetic/logic and device routing so experiments can be changed through programs.
  • 针对预报式纠缠的前馈需求，连接四通道 TDC、时间窗口事件判断、相位计算与 DDS 控制，配合触发和时钟模块传递补偿结果。Connected four-channel TDC, temporal event windows, phase computation and DDS control for heralded-entanglement feed-forward, with a trigger/clock module distributing corrections.
  • 参与硬件接口、固件与上位机联调，逐项核对探测输入、板上计算与 DDS 输出的控制逻辑，通过波形和相干振荡验证前馈效果。Worked on hardware interfaces, firmware and host integration, tracing detector inputs through board computation to DDS outputs and validating the feed-forward path with waveform and coherence measurements.

TTL / TDCTTL / TDC

在实验探测窗口内采集时间戳并执行事件判定与相位计算。Acquire timestamps within detection windows and perform event qualification and phase computation.

TCM 同步与路由TCM synchronization and routing

分发全局时钟、触发与跨板消息，使控制模块按统一时钟和确定性时序执行。Distribute global clocks, triggers and cross-board messages so modules execute with consistent timing semantics.

DDS / AWG 输出DDS / AWG output

接收补偿值并更新幅度、频率或相位，在硬件时序内完成后续控制。Receive correction values and update amplitude, frequency or phase within the hardware timing sequence.

实验验证Experimental validation

TDC 标定后的时间测量精度为 11.5 ps RMS。包含时间戳采集、相位计算与波形更新的端到端前馈延迟实测约为 800 ns；Ramsey 干涉中恢复的相干振荡验证了逐次相位补偿。After calibration, the TDC achieves 11.5 ps RMS timing precision. The measured end-to-end feed-forward latency, from timestamp acquisition and phase calculation to waveform update, is approximately 800 ns. Ramsey interference demonstrates restored coherent oscillations and validates shot-by-shot phase compensation.

团队相关工作：QuCtrl-BELLRelated team work: QuCtrl-BELL

She 等人的 QuCtrl-BELL 工作提供了这一控制平台的编译器架构：Python DSL 经 CFG、SSA、活跃变量分析和寄存器分配生成板级程序，将控制流与硬件状态表分离。The QuCtrl-BELL work by She et al. provides a compiler architecture for this control platform: a Python DSL lowers through CFG, SSA, liveness analysis and register allocation into board-level programs, separating control flow from hardware state tables.

MiniTrainSys：受控预训练与知识读出研究MiniTrainSys: from training systems to knowledge mechanisms

我独立开发 MiniTrainSys，用于检验模型训练与知识读出的研究假设。框架覆盖数据处理、分词、模型训练、分布式执行、检查点恢复、探针评测与路由分析，实验配置和结果可复现。核心问题是：模型已经记住事实，为什么仍可能无法读出相应知识？I built a training system as an experimental instrument: a reproducible path from documents and tokenization through models, distributed execution, checkpoints, probes, and routing analysis. The motivating question is simple: if a model memorizes a fact, why can it still fail to retrieve it?

训练流程与可切换执行后端One model, across the complete training stack

实现原始文档处理、Byte-BPE、Token Shard、无 Padding Packing、Dense / Sparse MoE、BF16 训练、DDP / FSDP、DCP 检查点与断点恢复。OpsBackend 将模型定义与执行后端分开，使同一模型和配置可以切换 PyTorch、Triton 与 CUDA 路径，减少实现差异对比较结果的干扰。Implemented document preparation, Byte-BPE, token shards, padding-free packing, Dense / Sparse MoE decoders, BF16 training, DDP / FSDP, and resumable DCP checkpoints. An OpsBackend boundary separates model semantics from PyTorch, Triton, and CUDA execution, keeping backend comparisons on the same model and configuration.

端到端性能评测与复现条件From throughput to reproducible evidence

性能评测计入数据加载、前向、反向、优化器更新、日志与同步，分别报告相同 Batch 和相同显存预算下的吞吐，并保留正确性校验、容量扫描与原始测量。系统优化用于缩短受控实验的迭代周期，训练收益以完整训练流程衡量，不能由单个算子的速度提升直接推断。Measurements cover data loading, forward and backward passes, optimizer updates, logging, and synchronization. Equal-batch and equal-memory comparisons are reported separately, with parity checks, capacity sweeps, and raw measurements retained. The purpose is faster controlled experimentation, measured at the complete training-step level.

事实相同，知识的可访问性为何不同The same facts, different retrieval structure

参考 Allen-Zhu 与 Li 的 bioS 范式，生成 10 万人物、每人 6 项事实，训练两个架构和优化配置相同、各约 4B Token 的 MoE。固定模板组与五种改写加句序重排组共用同一张事实表，主要区别在于事实呈现方式。两组均近乎完全记忆源文本；但仅输入姓名时，属性首 Token 的探针读出准确率分别为 12.83% 和 98.79%。Following the bioS methodology of Allen-Zhu and Li, I generated 100,000 people with six facts each and pretrained two matched MoEs for approximately 4B tokens apiece. Both use identical fact tables; the main change is fixed biographies versus five rewrites with sentence permutation. Both nearly memorize the source text, yet name-only first-token readout changes from 12.83% to 98.79%.

冻结骨干探针与条件干预Turning a behavior into a mechanism test

冻结骨干后，分别用传记前缀 P 探针与姓名输入 Q 探针测量首 Token 和完整属性的读出表现；通过关系暴露对照，排除“位置更晚所以更好”的简单解释。对共享首 Token 的样本，采用差分中的差分分析专家路由变化；再提供真实首 Token 作为 oracle 干预、重新训练读出探针，检验恢复完整属性所需的条件。With the backbone frozen, I separate first-token and whole-value readout under biography-prefix P probes and name-only Q probes. Relation-exposure controls test a simple late-position explanation. A route difference-in-differences analysis compares continuations sharing a first token; an oracle-first-token intervention with a fresh probe tests when the complete value becomes readable.

结果解释与后续验证A result should change the next experiment

实验支持以下解释：数据改写与句序重排改变了知识的访问方式，姓名输入可以支持各属性首 Token 的读出，完整属性的恢复仍依赖上下文与 Token 条件。这些观察提示，预训练语料应呈现可重组的组件与中间步骤；这一推断仍需在自然语料与更大模型上验证。The evidence supports a change in access structure: augmentation makes attribute-entry tokens available from the name, while subsequent value recovery remains context- and token-dependent. This motivates data that exposes reusable components and intermediate steps. Whether the same structure persists in natural corpora and larger models remains an empirical question.

研究错误识别、回退与纠正轨迹，检验包含错误和纠正过程的数据如何影响模型的推理行为。Study error recognition, backtracking, and correction trajectories, asking how error–correction data changes reasoning behavior.

在研 · CFG 与结构泛化In progress · CFG and structural generalization

用上下文无关文法控制层级结构与组合，测试训练中未出现过的配置，考察结构学习和泛化条件。Use context-free grammars to control hierarchy, composition, and unseen configurations, and test the limits of structural generalization.

下一步，追问什么？What comes next?

  • 模型记住的是整段模板，还是能够按需调用、重新组合的知识？Does the model learn a whole template, or knowledge that can be independently accessed and recombined?
  • 首 Token 与完整属性的读出表现为何存在差距？What causes the gap between first-token and complete-value readout?
  • 数据、路由与架构如何改变知识的内部访问路径？How do data, routing, and architecture change internal access to knowledge?

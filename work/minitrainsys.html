MiniTrainSys：从训练系统到知识机制MiniTrainSys: from training systems to knowledge mechanisms

我把训练系统做成可检验研究假设的实验装置：从文档、Tokenizer、模型与分布式执行到检查点、探针和路由分析，使用同一套可复现实验链路，追问“模型记住了事实，为什么仍不能把它读出来？”I built a training system as an experimental instrument: a reproducible path from documents and tokenization through models, distributed execution, checkpoints, probes, and routing analysis. The motivating question is simple: if a model memorizes a fact, why can it still fail to retrieve it?

同一个模型，贯通整条训练链路One model, across the complete training stack

实现原始文档处理、Byte-BPE、Token Shard、无 Padding Packing、Dense / Sparse MoE、BF16 训练、DDP / FSDP、DCP 检查点与断点恢复。以 OpsBackend 隔离模型定义和执行后端，在同一模型与配置下切换 PyTorch、Triton 和 CUDA 路径，避免比较两个实现时引入额外变量。Implemented document preparation, Byte-BPE, token shards, padding-free packing, Dense / Sparse MoE decoders, BF16 training, DDP / FSDP, and resumable DCP checkpoints. An OpsBackend boundary separates model semantics from PyTorch, Triton, and CUDA execution, keeping backend comparisons on the same model and configuration.

从吞吐量到可复现证据From throughput to reproducible evidence

性能评测覆盖数据加载、前向、反向、优化器更新、日志与同步。分别报告相同 Batch 和相同显存预算下的吞吐，保留正确性校验、容量扫描及原始测量。训练系统的价值是缩短受控实验的迭代周期，而不是把单个算子速度当作模型训练收益。Measurements cover data loading, forward and backward passes, optimizer updates, logging, and synchronization. Equal-batch and equal-memory comparisons are reported separately, with parity checks, capacity sweeps, and raw measurements retained. The purpose is faster controlled experimentation, measured at the complete training-step level.

同样的事实，不同的可读出结构The same facts, different retrieval structure

参考 Allen-Zhu 与 Li 的 bioS 范式，生成 10 万人物、每人 6 项事实；训练两个同架构、同优化配置、各约 4B Token 的 MoE。固定模板组与五种改写加句序重排组共享相同事实表，主要改变事实呈现。两组均近乎完全记忆源文本，姓名状态的属性首 Token 读出却从 12.83% 变为 98.79%。Following the bioS methodology of Allen-Zhu and Li, I generated 100,000 people with six facts each and pretrained two matched MoEs for approximately 4B tokens apiece. Both use identical fact tables; the main change is fixed biographies versus five rewrites with sentence permutation. Both nearly memorize the source text, yet name-only first-token readout changes from 12.83% to 98.79%.

把现象推进到机制检验Turning a behavior into a mechanism test

冻结骨干，分别测量传记前缀 P 探针与姓名输入 Q 探针的首 Token、完整属性读出；用关系暴露对照排除“位置更晚所以更好”的简单解释。再对共享首 Token 的样本做专家路由差分中的差分，并通过 oracle 首 Token 干预、重新训练读出探针，检验完整属性何时重新可读。With the backbone frozen, I separate first-token and whole-value readout under biography-prefix P probes and name-only Q probes. Relation-exposure controls test a simple late-position explanation. A route difference-in-differences analysis compares continuations sharing a first token; an oracle-first-token intervention with a fresh probe tests when the complete value becomes readable.

结论的价值，在于能指导下一次实验A result should change the next experiment

结果支持这样的解释：数据改写与排列改变了知识的访问结构，姓名可以成为各属性首 Token 的入口，后续值的恢复仍依赖上下文与 Token 条件。它提示预训练语料应呈现可重组的组件与中间步骤；这一推断在自然语料和更大模型上仍需要验证。The evidence supports a change in access structure: augmentation makes attribute-entry tokens available from the name, while subsequent value recovery remains context- and token-dependent. This motivates data that exposes reusable components and intermediate steps. Whether the same structure persists in natural corpora and larger models remains an empirical question.

在研 · 隐藏推理In progress · Hidden reasoning

基于合成任务分离推理深度、依赖结构与表面表达，研究隐藏状态中的计算过程。Use synthetic tasks to separate reasoning depth, dependency structure, and surface form, and study the computation represented in hidden states.

在研 · Regret 与错误恢复In progress · Regret and error recovery

关注错误识别、回退与纠正轨迹，研究错误—纠正数据如何改变模型的推理行为。Study error recognition, backtracking, and correction trajectories, asking how error–correction data changes reasoning behavior.

在研 · CFG 与结构泛化In progress · CFG and structural generalization

利用上下文无关文法控制层级结构、组合和训练未见配置，考察结构学习及泛化边界。Use context-free grammars to control hierarchy, composition, and unseen configurations, and test the limits of structural generalization.

下一步，追问什么？What comes next?

  • 模型学会的是整段模板，还是可以按需访问、重新组合的知识？Does the model learn a whole template, or knowledge that can be independently accessed and recombined?
  • 首 Token 可读出与完整属性可读出的差距，来自哪里？What causes the gap between first-token and complete-value readout?
  • 数据、路由与架构如何改变知识的内部访问路径？How do data, routing, and architecture change internal access to knowledge?

Continuum · Agent Research Workbench

Continuum takes its name from continuity: a task can continue across models, agents, and desktop or mobile devices. I extended an existing agent workbench with model switching, session handoff, task delegation, and tool integrations. A project workspace brings together conversations, code, and experiment status. I use it for literature review, implementation, training checks, and documentation, and can resume conversations or inspect tasks and training status on my phone.

Problem

A research task often involves model conversations, Linux, Git, data processing, training platforms, and shared documents. When these tools are separate, changing models or devices means explaining the task again, finding files, and reconstructing progress.

Model adapters and switching

The workbench connects to backends including OpenAI and Anthropic through configurable API, proxy, and account profiles. Switching models preserves the project workspace and task state, so work can continue without recreating the working environment.

Session history and context handoff

Session history, branches, and handoff preserve the conversation and task state when work moves to another model or agent. The receiving agent can continue from the research, code changes, and checks already completed.

Task delegation and subagents

The harness protocol supports task delegation, subagent organization, tool calls, and result handoff. Different models can handle research, implementation, or review. In actual research workflows, I have used more than ten main agents with around ten subagents per main agent.

MCP tools and skills configuration

Custom MCP connections, task presets, and skills configure the tools and instructions available to each task. Integrations include reading and writing Feishu documents, bot collaboration, authorized information retrieval, and multilingual translation for research and documentation.

Linux, Git, and training tools

Linux Bash, Git, file management, Docker, training and data platforms, and W&B experiment tracking are accessible from the workspace. Agents can inspect code, job status, logs, and metrics, then edit code, run commands, and check the results. Users can review changes and track progress in the same workspace.

Desktop and mobile continuity

Sessions, workspaces, and input drafts are synchronized across desktop and mobile, with voice input available on the phone. The mobile app supports switching projects and branches, inspecting Git history, continuing tasks, and checking training status.

Ongoing development questions

Further work focuses on context management and inspectable tool use: how much context a model or task handoff needs, how to prevent histories from growing without purpose, and how users can trace tool actions, verify results, and resume unfinished work.

Experimental conditions & contribution scope
Extended an existing baseline through feature development, protocol adaptation, and integration. Usage has involved more than ten main agents with about ten subagents each; this is not a concurrency benchmark.

Continuum · Agent 研发工作台Continuum · Agent Research Workbench

Continuum 取“连续、接续”之意，是我基于既有 baseline 扩展的 Agent 研发工作台。同一项任务可以交接给不同模型或 Agent，也可以在电脑与手机之间继续处理。工作台支持模型切换、会话上下文交接、任务委派与工具调用，在项目工作区集中查看对话、代码和实验状态。我用它调研资料、修改代码、检查训练和撰写文档；离开电脑后，可以在手机上接续会话、查看任务与训练状态。Continuum is named for continuity: the same task can continue across models, agents, and desktop or mobile devices. It is an agent research workbench that I extended from an existing baseline, adding model switching, session handoff, task delegation, and tool integrations. Projects, conversations, code, and experiment status share a workspace, supporting work from literature review through implementation, training checks, and documentation. Away from the desktop, I can resume a session and check tasks or training status on my phone.

CONTINUUM / DESKTOP WORKSPACE

问题Problem

研究任务经常需要同时使用模型对话、Linux、Git、数据处理、训练平台与协作文档。工具和会话分散时，切换模型或设备就需要重新说明任务、查找文件、整理进度。A research task often involves model conversations, Linux, Git, data processing, training platforms, and shared documents. When these tools are separate, changing models or devices means explaining the task again, finding files, and reconstructing progress.

模型接入与切换Model connections and switching

接入 OpenAI、Anthropic 等模型后端，管理 API、Proxy 与账号配置，支持在任务中选择或切换模型。模型适配与工作区管理相互独立，同一个项目使用不同模型时，无需重新建立工作环境。Connect backends including OpenAI and Anthropic, manage API, proxy, and account configurations, and select or switch models during a task. Model connections are separate from project workspaces, so a project can use different models without setting up another working environment.

会话历史与上下文交接Session history and context handoff

保存会话历史，支持分支与 Session Handoff。切换模型或 Agent 时，交接已有对话和任务状态，使后续工作能够接着已有调研、代码修改和检查结果继续。Keep session history and support branches and session handoff. When moving to another model or agent, pass along the conversation and task state so work can continue from the research, code changes, or checks already completed.

任务委派与子 Agent 协作Task delegation and subagents

通过 Harness 协议分派任务、组织子 Agent、调用工具和交接结果，让不同模型分别承担调研、实现或复核。实际研发中使用过十余个主 Agent、每个主 Agent 约十个子 Agent 的分层协作。Use the harness protocol to delegate tasks, organize subagents, call tools, and hand back results. Different models can take on research, implementation, or review. In actual research workflows, I have used more than ten main agents, with around ten subagents per main agent.

MCP 工具与 Skills 配置MCP tools and skills configuration

支持自定义 MCP 连接、任务预设和 Skills 配置，按任务选择工具与指令。已接入飞书文档读写、机器人协作、经授权的资料检索和多语言翻译，供调研与文档工作使用。Configure custom MCP connections, task presets, and skills, selecting tools and instructions for each task. Integrations include Feishu document operations, bot collaboration, authorized knowledge retrieval, and multilingual translation for research and documentation.

Linux、Git 与训练工具Linux, Git, and training tools

接入 Linux Bash、Git 和文件管理，并连接 Docker、训练与数据平台、W&B 实验追踪。Agent 可以检查代码、作业状态、日志和指标，定位问题后修改代码、运行命令并验证结果；使用者可在工作区审阅改动、跟踪进度。Connect Linux Bash, Git, and file management with Docker, training and data platforms, and W&B experiment tracking. Agents can inspect code, job status, logs, and metrics, then make changes, run commands, and check results. The user reviews changes and follows progress in the workspace.

电脑与手机接续工作Continue work across desktop and mobile

同步会话、工作区和输入草稿，并支持手机语音输入。移动端可以切换项目与分支、查看 Git 历史、接续任务和检查训练状态。Synchronize sessions, workspaces, and input drafts, with voice input on mobile. The mobile app supports project and branch switching, Git-history inspection, task continuation, and training-status checks.

我在持续研究的问题The questions I keep working on

我继续关注两件事：模型切换和任务交接需要保留多少上下文，怎样避免历史消息无序累积；Agent 调用工具后，怎样让使用者查清执行过程、复核结果，并继续处理未完成的任务。Two questions guide further work: how to preserve enough context when changing models or handing over tasks without accumulating an unwieldy history, and how to make tool actions clear enough for a user to inspect the results and continue unfinished work.

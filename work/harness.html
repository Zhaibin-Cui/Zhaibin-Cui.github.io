Continuum · Agent 研发工作台Continuum · Agent Research Workbench

Continuum 取“连续、接续”之意：让同一项工作能在不同模型、Agent 和电脑、手机之间接着做。它是我基于既有 baseline 扩展的 Agent 研发工作台，支持模型切换、会话上下文交接、任务委派和工具调用。项目、对话、代码与实验状态放在同一个工作区中，可以从资料调研继续到代码修改、训练检查和文档撰写；离开电脑后，也能在手机上接续会话、查看任务和训练状态。Continuum is named for continuity: the same task can continue across models, agents, and desktop or mobile devices. It is an agent research workbench that I extended from an existing baseline, adding model switching, session handoff, task delegation, and tool integrations. Projects, conversations, code, and experiment status share a workspace, supporting work from literature review through implementation, training checks, and documentation. Away from the desktop, I can resume a session and check tasks or training status on my phone.

问题Problem

一项研究往往要同时使用模型对话、Linux、Git、数据处理、训练平台和协作文档。如果这些工具各用各的，换一个模型或设备，就需要重新解释任务、查找文件和整理进度。A research task often involves model conversations, Linux, Git, data processing, training platforms, and shared documents. When these tools are separate, changing models or devices means explaining the task again, finding files, and reconstructing progress.

模型接入与切换Model connections and switching

接入 OpenAI、Anthropic 等模型后端，管理 API、Proxy 和账号配置，并在任务中选择或切换模型。模型接入和项目工作区分开处理，同一个项目可以使用不同模型，而不必另建一套工作环境。Connect backends including OpenAI and Anthropic, manage API, proxy, and account configurations, and select or switch models during a task. Model connections are separate from project workspaces, so a project can use different models without setting up another working environment.

会话历史与上下文交接Session history and context handoff

保存会话历史，支持分支与 Session Handoff。换用其他模型或 Agent 时，可以交接已有对话和任务状态，让后续工作沿着已完成的调研、代码修改或检查结果继续。Keep session history and support branches and session handoff. When moving to another model or agent, pass along the conversation and task state so work can continue from the research, code changes, or checks already completed.

任务委派与子 Agent 协作Task delegation and subagents

通过 Harness 协议分派任务、组织子 Agent、调用工具和交回结果，让不同模型分别承担调研、实现或复核。实际研发中使用过十余个主 Agent、每个主 Agent 约十个子 Agent 的分层协作。Use the harness protocol to delegate tasks, organize subagents, call tools, and hand back results. Different models can take on research, implementation, or review. In actual research workflows, I have used more than ten main agents, with around ten subagents per main agent.

MCP 工具与 Skills 配置MCP tools and skills configuration

配置自定义 MCP 连接、任务预设和 Skills，按任务选择需要的工具与指令。已接入飞书文档读写、机器人协作、经授权的资料检索和多语言翻译，用于调研与文档工作。Configure custom MCP connections, task presets, and skills, selecting tools and instructions for each task. Integrations include Feishu document operations, bot collaboration, authorized knowledge retrieval, and multilingual translation for research and documentation.

Linux、Git 与训练工具Linux, Git, and training tools

接入 Linux Bash、Git 和文件管理，并连接 Docker、训练与数据平台、W&B 实验追踪。Agent 可以查看代码、作业状态、日志和指标，定位问题后修改、运行并检查结果；使用者在工作区审阅改动和跟踪进度。Connect Linux Bash, Git, and file management with Docker, training and data platforms, and W&B experiment tracking. Agents can inspect code, job status, logs, and metrics, then make changes, run commands, and check results. The user reviews changes and follows progress in the workspace.

电脑与手机接续工作Continue work across desktop and mobile

同步会话、工作区和输入草稿，并支持手机语音输入。移动端可以切换项目与分支、查看 Git 历史、接续任务和检查训练状态。Synchronize sessions, workspaces, and input drafts, with voice input on mobile. The mobile app supports project and branch switching, Git-history inspection, task continuation, and training-status checks.

我在持续研究的问题The questions I keep working on

我关心两个具体问题：换模型或交接任务时，怎样保留足够的上下文，又不让历史消息不断堆积；Agent 调用研发工具后，怎样让使用者看清做了什么、检查结果，并继续处理未完成的部分。Two questions guide further work: how to preserve enough context when changing models or handing over tasks without accumulating an unwieldy history, and how to make tool actions clear enough for a user to inspect the results and continue unfinished work.

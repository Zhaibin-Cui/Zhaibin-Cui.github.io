01 / RESEARCH STATEMENT

数据、表征、推理。 以及它们背后的架构。Data. Representations. Reasoning. And the architecture underneath.

我研究语言模型怎样从数据中学到知识，以及何时能把这些知识用在回答和推理中。我关注数据呈现、内部表征、推理过程和模型架构，用合成语料、受控训练和冻结骨干探针，分辨模型记住了什么、能读出什么、又完成了哪些计算。为快速搭建和复现实验，我从零开发了 MiniTrainSys，并检验每项结论在什么条件下成立。I study how language models learn knowledge from data and when they can use it to answer questions and reason. My work focuses on data presentation, representations, reasoning, and architecture. I use synthetic corpora, controlled training, and frozen-backbone probes to distinguish what a model memorizes, what can be read out, and what computation it performs. I built MiniTrainSys from scratch to set up and reproduce experiments quickly, and to test where their conclusions hold.

实验物理训练让我习惯先拆解系统、隔离变量，再判断解释是否成立。从量子测控到分布式训练，我愿意深入底层，也重视把新想法迅速做成可测量的实验。Experimental physics shaped how I work: decompose a system, isolate variables, then test the explanation. From quantum control to distributed training, I work close to the fundamentals and build new experiments quickly.

01 / DATA

数据组织与知识学习Data organization and knowledge learning

事实相同，换一种措辞、句序或采样方式，模型能否更容易读出知识？这种变化与记住训练文本有什么区别？With the same facts, do different wording, sentence order, or sampling make knowledge easier to read out? How does that differ from memorizing the training text?

使用同一张事实表，改变文本的呈现方式，保持模型和优化配置一致。分别测量源文本记忆、属性首 Token 和完整属性读出，同时记录两组训练 Token 预算的差异。Use the same fact table with different text presentations while keeping the model and optimization settings fixed. Measure source-text memorization, first-token readout, and whole-value readout separately, and record any difference in training-token budgets.

实验依据与下一步Evidence & next questions +
已完成的对照Completed experiment

在 bioS 实验中，我把 10 万人物、每人 6 项事实写成固定模板或改写、重排后的文本。两组模型都几乎记住了源文本，但冻结骨干后，仅输入姓名的首 Token 读出准确率分别为 12.83% 和 98.79%。In the bioS experiment, I used 100,000 people with six facts each to construct fixed-template biographies and paraphrased, reordered text. Both models nearly memorized the source text. With the backbone frozen and only a name as input, first-token readout accuracy was 12.83% and 98.79%, respectively.

两个同架构 MoE 各训练约 4B Token；计划 Token 预算相差 0.62%。结果对应冻结骨干 Q 探针，不是开放式问答生成准确率。Two matched MoEs are trained for approximately 4B tokens each; scheduled-token budgets differ by 0.62%. The result measures frozen-backbone Q-probe readout, not free-form question-answer generation.

继续检验Questions to test next

接下来分别检验改写、句序和采样的作用，再看合成语料上的读出差异能否在自然语料、不同训练配方和更大模型上复现。Next, I want to isolate the effects of paraphrasing, sentence order, and sampling, then test whether the readout differences recur with natural corpora, other training recipes, and larger models.

02 / REPRESENTATIONS

知识表征与条件读出Knowledge representations and conditional readout

模型记住事实后，为什么从姓名状态能读出属性首 Token，却仍读不出完整属性？补充一个 Token 或改变上下文，究竟改变了什么？After a model memorizes a fact, why can the name state reveal the first token but still fail to recover the full value? What changes when we supply a token or alter the context?

冻结骨干，比较输入传记前缀的 P 探针和仅输入姓名的 Q 探针，分别测量首 Token 与完整值。随后提供真实首 Token、重新训练探针，并用差分中的差分分析比较专家路由变化。Freeze the backbone and compare P probes given a biography prefix with Q probes given only a name. Measure first-token and whole-value readout, then supply the true first token, train fresh probes, and compare routing changes using difference-in-differences analysis.

实验依据与下一步Evidence & next questions +
已完成的干预Completed intervention

在增强语料条件下，提供真实首 Token 并重新训练读出探针后，完整属性读出从 45.28% 提高到 96.38%。这说明，在该实验设置中，后续值能否被读出取决于提供的 Token 和上下文。With augmented data, supplying the true first token and training a fresh readout probe increased whole-value readout from 45.28% to 96.38%. In this setup, whether the continuation can be read out depends on the supplied token and context.

Oracle 提供真实答案的首 Token；该实验不等于模型自主生成完整答案。探针留出的人物仍在骨干预训练中出现过。The oracle supplies the first token of the true answer; this is not autonomous generation of the complete answer. People held out from probe training were still present in backbone pretraining.

专家路由差异是访问过程的观测证据，不能据此断言某个专家独立存储某条事实。Routing differences characterize the access process; they do not establish that an individual expert stores a particular fact.

继续检验Questions to test next

我想进一步区分三个问题：表征里有没有相关信息、什么输入能让它被读出、读出器本身做了多少计算。后续通过输入和表征干预，检验这些解释对层位置、路由和架构的依赖。I want to separate three questions: whether the representation contains the information, which inputs make it readable, and how much computation the readout itself performs. Further input and representation interventions will test how these explanations depend on the layer, routing, and architecture.

03 / REASONING

隐藏推理与错误修正Hidden reasoning and error correction

没有显式思维链时，模型怎样完成多步计算？训练中加入错误识别、回退和修正过程，会怎样改变它的解题方式？How does a model carry out multistep computation without an explicit chain of thought? How do error recognition, backtracking, and correction in training affect the way it solves a task?

这部分实验设计用合成任务控制依赖关系和推理深度，比较只含正确步骤的轨迹与包含错误、修正步骤的轨迹。最终答案、过程行为和隐藏状态分别评估。The experimental design uses synthetic tasks to control dependencies and reasoning depth, comparing entirely correct trajectories with ones that include errors and corrections. It evaluates final answers, intermediate behavior, and hidden states separately.

实验依据与下一步Evidence & next questions +

The completed mechanism experiments concern factual readout; the same tools provide a starting point for the reasoning studies.

This work is ongoing; the completed bioS readout experiments do not establish results for these reasoning questions.

04 / ARCHITECTURE

模型架构与结构泛化Model architecture and structural generalization

使用相同训练信号时，注意力、位置编码和路由结构的选择，怎样影响模型组合已有知识、处理未见结构的能力？With the same training signal, how do attention, positional encoding, and routing affect a model’s ability to combine what it has learned and handle unseen structures?

语言实验使用上下文无关文法（CFG）控制层级、深度和组合，并设计未见配置测试。视觉部分结合交互模块、位置编码和蒸馏目标的消融，比较模型结构与训练配方各自的影响。For language experiments, context-free grammars (CFGs) control hierarchy, depth, and composition, with tests on unseen configurations. In vision, ablations of interaction modules, positional encoding, and distillation objectives help distinguish architecture effects from training-recipe effects.

实验依据与下一步Evidence & next questions +
已有架构研究Existing architecture work

在 PaGE 合作项目中，我参与场景与头部之间的双向 Cross-Attention、共享场景坐标系的 2D RoPE，以及蒸馏数据研发。论文用结构和目标消融检查这些设计；完整蒸馏 ViT-B 在 3 个数据集的 9 项指标中，有 7 项超过论文采用的人类基线。In PaGE, I contributed to bidirectional scene–head cross-attention, 2D RoPE in a shared scene coordinate system, and distillation data. The paper examines these designs through architecture and objective ablations. The complete distilled ViT-B exceeds the paper’s human baselines on seven of nine metrics across three datasets.

7/9 是完整模型的论文结果，不能归因于单个模块。PaGE 的场景与头部是两个视觉分支。Seven of nine is a paper-level result for the complete model, not an effect attributable to one module. PaGE's scene and head branches are both visual.

进行中的研究方向Research in progress

CFG 结构学习与泛化研究仍在进行。我想在明确训练预算和模型容量的条件下，检验模型是否学到了可组合的结构，以及哪些架构选择会改变它对未见结构的表现。Work on CFG structure learning and generalization is ongoing. With training budgets and model capacity specified, I want to test whether models learn compositional structure and which architectural choices change their performance on unseen structures.

HOW I WORK

我的实验方法。How I run experiments.

遇到模型行为差异，我先提出几种可能的解释，再设计能区分它们的最小对照。用合成数据固定事实与依赖关系，记录训练预算和配置；用冻结骨干探针、输入干预和消融，分别检查记忆、读出与计算。我习惯自己把数据、训练和评测工具搭起来，尽快跑出可复现的实验，同时保留原始测量、失败案例和结论成立的条件。When two models behave differently, I start with possible explanations and design the smallest control that can distinguish them. Synthetic data fixes the facts and dependencies; training budgets and settings are recorded. Frozen-backbone probes, input interventions, and ablations test memorization, readout, and computation separately. I build the data, training, and evaluation tools to run reproducible experiments quickly, keeping the raw measurements, failed cases, and conditions behind each conclusion.

06 / THE PERSON BEHIND THE WORK

崔翟斌Zhaibin Cui

我研究语言模型如何从数据中学到知识，以及模型架构和训练规模如何影响表征与推理。在 MiniMax，我参与大规模预训练；在 MiniTrainSys 中，我从零搭建训练框架，用合成数据和受控实验检验模型行为；在 PaGE 中，我参与空间感知视觉建模与蒸馏。实验物理训练让我习惯拆开变量、追问原因，也习惯自己实现工具，尽快验证一个想法，并记录结论成立的条件。I study how language models learn knowledge from data, and how architecture and training scale affect representations and reasoning. I contribute to large-scale pretraining at MiniMax, built MiniTrainSys from scratch for controlled studies with synthetic data, and work on spatially aware visual modeling and distillation in PaGE. Experimental physics taught me to isolate variables and look for explanations. I also build the tools needed to test ideas quickly and document the conditions under which a result holds.
